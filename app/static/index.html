Several parties train one model. No one sees the weights or anyone else's data.

Each party contributes private data to a model running inside a confidential GPU. The model trains on it and is tested, and the new weights are hashed and signed. No party sees another's data, and the weights never leave. A signed record of every version is public.

In this demo the private data is a cipher. Each party sends a secret key, the enclave turns it into training examples, and the model learns to decode messages written in that cipher.

What this does and does not show

It shows
  • Which code and which base model ran, from the hardware attestation.
  • The order of the updates, and each version's scores and weights hash, from the signed record.
  • That the record was signed by a key that existed only inside that enclave.
  • That no route in the released code returns a key, training data or weights.
It does not show
  • That the weights still exist. They lived in memory and were gone when the enclave stopped.
  • That the weights hash can be reproduced. Training is not bit-for-bit repeatable, so the hash commits to the weights that existed.
  • That the model keeps training data secret. A model can memorize what it trains on, which is why decoding needs the contributor's token.

The ledger

Each row includes the hash of the row before it, so changing a past row breaks every row after it. The key commitment is a salted hash of the contributor's key; only the contributor holds the salt.
